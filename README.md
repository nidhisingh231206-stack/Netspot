# project title
Net Spot- It is a real time network attributes measuring application that recommends the best nearby location admist any hinderance faced by the user while working online. It is designed to help its users monitor their network performance in real time.

# Objectives
Tells the nearby location with better network connectivity
Monitor internet's speed in real time
Display network signal strength
Simple and an interactive interface 

# key Features
Real time network speed monitoring
network connectivity status
simple and intuitive user interface

# Technologies used
Programming Languages- C, C++, Pyhton
Frontend- Bootstrap, React
Backend- C++ HTTP server and JSON API
